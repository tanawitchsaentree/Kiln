# 08-seed-catalogue — Seed catalogue

## Conditions

Many similar items that need to be compared against each other rather than considered one at a
time. The reader is comparison shopping, not browsing for mood, so plain accurate description beats
persuasion — a claim that can't be checked against the plant itself is a liability, not a selling
point. Illustration exists to confirm identity, not to set atmosphere.

## Home vector

`C5 T6 G2 S3 M1 D6` — passes `scripts/check_vector.py` (spread 5, no concentration or payment
issue). No axis reaches the 7 that `intensity.md` treats as the threshold for loud, so this lineage
has no loud axis at home position, in the same legitimate quiet-but-confident category as
`10-field-guide`, `15-manuscript-margin`, and `16-parts-diagram`. Type sits highest at 6 and carries
the most weight of the six: the captions are plain but confident and doing real comparative work —
variety name, days-to-maturity, price — scanned and compared across many similar entries, so type
does more of the system's work than colour or illustration without ever needing to spend past 6 to
do it.

## Hierarchy logic

Not size, but repetition of a fixed field order: name, then maturity window, then price, in that
exact sequence in every entry, so the reader's eye learns where to look once and reuses that lookup
across the whole catalogue. The second device is a single differentiated weight reserved for the
one identifying label — the cultivar name set slightly heavier than its description — while
everything else in the entry holds one flat weight.

## Colour logic

Three roles: a paper-toned ground, a text ink for the comparative fields, and one reserved accent
for a call-out that isn't about the plant itself — new variety, limited stock, on sale. Illustration
colour is not counted as a system role; it belongs to identification, not to the interface. The rule
for the reserved accent: it marks a flag about availability, never a quality judgement about the
plant.

## Rhythm

The repeating unit is the entry block: a fixed illustration-to-caption ratio, tiled down the column
at a constant height derived from that ratio. Every entry occupies the same vertical span regardless
of how much or little there is to say about it, so a short entry and a long one still compare at the
same offsets.

## Signature move

The same field order, in the same position, in every entry, so that comparing "days to maturity"
across ten varieties means reading the same vertical offset ten times rather than hunting for it
anew each time. Break the field order once and the comparison the whole catalogue exists to enable
breaks with it.

## What it hands the system for free

A scanning logic the reader only has to learn once: because every entry shares a template, the eye
trained on entry one already knows where to look in entry forty. It also hands a ready answer to
"how do I show hierarchy without a hero," since no single entry needs its own designed hierarchy —
it inherits the template's.

## Type character

Plain and confident, set rather than drawn — a workhorse face at a size that holds up in a dense
column. Bold is spent sparingly, only on the one identifying label per entry, never for emphasis
elsewhere. Numerals are tabular so prices and day-counts align down the column for comparison.

## Voice

Plain, descriptive, warm-neutral. Claims are falsifiable — "matures in 65 days," not "irresistibly
sweet" — because the reader is comparing, not being sold to. Warmth is allowed in the description
but never at the expense of a checkable fact.

## Failure mode

Pushed toward an identity or marketing surface, it goes bland: a template built for comparison has
no single moment of impact, and it reads as a spec sheet where a brand statement was wanted. Pushed
too far by raising chroma or letting illustration carry mood instead of identification, the
catalogue's central promise — plain accurate description — stops being credible, and the reader
starts reading the copy the way they'd read an advertisement, with suspicion instead of trust.

## What it cancels

Cancels display type as a hierarchy device — hierarchy here is positional and repetitive, not a
size jump. Cancels illustration used for atmosphere; every image has to serve identification and be
labelled as such. Cancels an asymmetric or broken grid, since the comparison this lineage exists for
depends on every entry landing at the same layout.

## Behaviour pulled off home

The fixed field order survives most pulls, because it costs nothing to keep even as colour or
density shifts. What breaks first is the plain-caption device: if type violence is pushed well past
6 toward something closer to 9, competing weights start fighting for attention within one entry, and
the "read the same offset every time" trust that makes comparison possible collapses. Grid can loosen
somewhat before the template itself is unrecognizable, but the field order is the one thing that
cannot move without the lineage stopping being this lineage.
